# Personal Portfolio Website

A responsive personal portfolio built with HTML5, CSS3, and JavaScript.

## Project structure

```text
.
├── index.html
├── css/
│   ├── variables.css
│   ├── style.css
│   └── responsive.css
├── js/
│   ├── navigation.js
│   └── contact-form.js
├── images/
├── .gitignore
└── README.md
```

`index.html` is the entry point. Shared CSS variables belong in
`css/variables.css`, base and component styles in `css/style.css`, and
responsive adjustments in `css/responsive.css`. Navigation behavior is in
`js/navigation.js`, and front-end contact-form validation is in
`js/contact-form.js`. Put project image assets in `images/` and add the profile
image at `public/profile.png`.

Open `index.html` in a browser to preview the portfolio. The contact form
performs front-end validation only and does not send messages.
